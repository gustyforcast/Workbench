# Workbench

This repo is Tim Deacon's (@gustyforcast) **personal planning hub** — the single place where portfolio specs, audits, side-project planning documents, and GitHub-level decisions live. It is not a software project; it has no tests, no build system, and no deployable code.

## What belongs here

- Portfolio audits (`audit.md`) — snapshots of all repos with showcase/archive/delete recommendations
- Side-project specs and design docs — one file per project, drafted before code starts
- Cross-repo decisions — e.g. naming conventions, licensing choices, pinned-profile strategy
- Career-facing notes that don't belong inside any single app repo

## What does not belong here

- Source code (put it in its own repo)
- App Store or publishing assets (keep those in the project repo)
- Secrets, API keys, or credentials

## Context: who Tim is

Senior subsea engineer (FEA, Python automation, pipeline integrity) who also ships Swift apps as side projects. The GitHub profile needs to serve both audiences:

1. **Engineering** — Python tools for structural/pipeline analysis, automation, data processing
2. **iOS/Mac** — Swift apps shipped on the App Store

See `audit.md` for the current state of all repos and the recommended action list.

## Commercial app policy

StillTime, PhotoFlow, and any future paid app stay private permanently. Public repos are limited to tools, libraries, and learning work. Never suggest making a commercial app repo public.

## Working in this repo

Plain Markdown files only. No special tooling required — edit in any editor or directly on GitHub. Commit messages should be short and descriptive (`add initial portfolio audit`, `update showcase checklist`, etc.).
